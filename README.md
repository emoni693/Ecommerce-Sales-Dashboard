# Business Sales Dashboard (Power BI)

## 📊 Project Overview
This project analyzes e-commerce sales data to identify best-selling products, sales trends, and top revenue-generating categories using **Power BI**.

## 🧠 Key Insights
- Top-selling products by revenue and quantity
- Monthly and yearly sales trends
- Country-wise sales distribution
- Average order value and total revenue KPIs

## 🛠️ Tools Used
- Power BI
- DAX
- Data Cleaning & Modeling
- Excel / CSV datasets (from Kaggle)

## 📁 Files
- `Ecommerce_Sales_Dashboard.pbix` – Main Power BI dashboard
- `online_retail_II.xlsx`, `Year 2009-2010.csv`, `Year 2010-2011.csv` – Source data
- `README.md` – Project details
